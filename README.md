# 🎯 24x7 AI Job & Internship Sniper Agent

Ye AI Agent live tech job boards (Remotive, Arbeitnow, Jobicy, etc.) ko 24x7 monitor karta hai:
1. **Live Scraping & API Integration:** Har 10 minute me 300+ live openings scan karta hai.
2. **AI Skill Matching:** Aapke skills (Android, Kotlin, Jetpack Compose, Python, SDE) aur target roles ke hisaab se match score calculate karta hai (0 - 100%).
3. **Instant Telegram Alerts:** High-match opening milte hi apply link ke sath turant alert bhejta hai.
4. **Tailored Cold Pitch:** Har company aur role ke liye ready-to-send personalized cold email draft karke deta hai!

---

## 📁 Files:
* **`agent.py`**: 24x7 continuous background monitoring loop.
* **`test_sniper.py`**: Quick 1-cycle test script.
* **`job_sources.py`**: Multi-source live job fetcher.
* **`ai_matcher.py`**: Skill match engine + Cold Pitch generator.
* **`telegram_alert.py`**: Rich Markdown Telegram notifier.
* **`Start_Job_Sniper.bat`**: 1-click launcher.
* **`Run_Silent_Background.vbs`**: Silent background runner (no terminal window).
* **`.env`**: Configuration for roles, skills, bot token, and minimum match score.
